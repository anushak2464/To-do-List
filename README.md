 To-Do Task Manager

 Trainee Name : Anusha Babu K


 Project Description

A simple To-Do Task Manager built using HTML, CSS, and JavaScript. It helps users add, manage, complete, edit, and delete tasks.

 Implemented Features

* Add new tasks
* Display all tasks
* Mark tasks as completed
* Edit existing tasks
* Delete tasks with confirmation
* Display total, completed, and remaining task counts
* Filter tasks by All, Completed, and Pending
* Save tasks using Local Storage
* Clear all completed tasks
* Display task creation date

 JavaScript Concepts Used

* Variables (let and const)
* Functions
* Event Listeners
* DOM Manipulation
* Arrays and Objects
* Array Methods (forEach, filter)
* Conditional Statements
* Local Storage
* JSON (JSON.stringify and JSON.parse)
* String Methods (toLowerCase, includes, trim)

 Bonus Features Completed

* Clear Completed Tasks
* Task Creation Date
* Confirmation Before Deleting a Task

 Technologies Used

* HTML
* CSS
* JavaScript

 How to Run the Project

1. Open the project folder.
2. Open index.html in a web browser.
3. Start adding and managing your tasks.


 Conclusion

This project helped me understand the fundamentals of JavaScript, DOM manipulation, event handling, and Local Storage by building a practical web application.
